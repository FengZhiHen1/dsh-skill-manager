1. `目录配置与状态存储.md`：先读目录语义、settings 意图形状、storage 域表形状与并发契约。

3. `挂载与同步.md`：读挂载物化与对账。
4. `插件运行时.md`：最后读包形态、部署、传输、调度与 UI。
